우클릭 메뉴 케이스

카드를 어떤 상태에서 우클릭하느냐에 따라 뜨는 메뉴를 전부 펼쳐 정리했습니다. 회색은 AS-IS 그대로(베타 실측 10/12), 파란색은 이번에 추가되는 항목입니다.
파란 항목을 누르면 인터넷 상품 관리 목업을 그 상태로 띄워 실제 모달 · 토스트가 실행됩니다.

고른 왼쪽 열 카드 초록선으로 이어진 오른쪽 열 카드 우클릭한 카드 미적용 기본값고른 카드의 기본값
세트 안 왼쪽 열 = 인터넷상품 · TV채널 · 전화상품, 오른쪽 열 = 기본WIFI · 셋탑박스 · 전화기기. 케이스 제목은 무엇을 하는지(왼쪽 열 카드를 고르지 않고 / 고른 뒤 · 어느 카드를 우클릭), 회색 칩은 그때의 데이터 상태입니다.
초록선 고른 카드와 우클릭한 카드 사이 판매 연결 등록 그 상품 조합이 속성 조합에 등록됐는지 같은 속성 조합 같은 속성 조합에 이미 등록된 다른 상품 조합이 있는지 기본값 우클릭한 카드가 고른 카드의 기본값인지

「위로 / 아래로」는 카드 위치에 따라 빠집니다 (AS-IS)

칸 안에서 첫 카드엔 「위로」, 마지막 카드엔 「아래로」가 없습니다. 카드가 하나뿐이면 둘 다 없습니다. 상품 · 세트상품 · 결합할인 항목 모두 같은 규칙이고, 선택 상태와 무관합니다.
아래 케이스의 메뉴는 모두 칸 중간 카드 기준이라 둘 다 표시했습니다. 카드 예시는 칸의 일부만 잘라 그린 것입니다.

인터넷세트 인터넷

왼쪽 열(인터넷상품)과 오른쪽 열(기본WIFI)의 기존 메뉴가 다릅니다 — 인터넷상품엔 「금지 코드 설정」이 없고, 기본WIFI엔 「금지코드 설정(단일)」이 있습니다.
「미적용」은 메뉴가 달라 별도 케이스로 관리합니다 — 아래 인터넷세트 · 「미적용」 참고.

인터넷세트 · 「미적용」 인터넷

「미적용」의 기존 메뉴는 「사용 / 미사용」 하나뿐입니다 — 고른 인터넷상품과 미적용 사이의 초록선 연결 / 해제 버튼(카드 사용중지 아님). 요금 · 할인 같은 기존 메뉴와 「플랫폼 노출 설정」은 어느 경우에도 없습니다.

인터넷 외 TV · 인터넷전화 · 일반전화

TV세트로 예시를 들었습니다. 인터넷전화 · 일반전화도 같습니다. 인터넷과 달리 왼쪽 열(TV채널 · 전화상품)에도 「금지 코드 설정」이 있고, 「상품 조합 등록」이 없습니다(초록선 상품 조합이 자동으로 속성 조합에 들어감).

결합할인 결합할인 탭

상품 조합이 없어 선택 상태와 무관합니다. 바뀌는 건 「설명 바꾸기」 → 「설명 수정」 하나 — 분류는 새 모달로 대체, 항목은 이름만 바꾸고 모달은 AS-IS 그대로입니다. 그 밖의 상품군(부가서비스 · 기타상품 등)은 「설명 바꾸기」 AS-IS 그대로.

여기 없는 것
· 인터넷 외 오른쪽 열의 「미적용」 — AS-IS에도 있고 메뉴는 「사용 / 미사용」 하나. 인터넷과 같은 추가 항목을 둘지 확인 필요
· 미사용 세트상품(「미사용 보기」를 켰을 때만 보임) — 상품 조합으로 우클릭해도 「기본값 지정」이 뜨지 않음
· 「우선순위 변경 (기본)」 괄호 안은 현재 우선순위(AS-IS)
