상품 연결 등록 — 인터넷 상품 우클릭
위 화면에서 바로 해볼 수 있습니다. 인터넷세트에서 왼쪽 인터넷상품 → 오른쪽 기본WIFI 순으로 클릭한 뒤 기본WIFI 위에서 우클릭하세요. 초록 선이 이미 있는 짝이면 「상품 연결 관리에서 보기」, 없는 짝이면 「상품 연결 등록」이 뜹니다. 등록하면 초록 선이 새로 그려집니다.
1진입 — 우클릭 메뉴에 항목 하나 추가1그룹 끝 · 위 화면 우클릭 메뉴
DESCRIPTION

이미 연결이 있으면 메뉴 항목이 바뀝니다 — 「상품 연결 등록」 대신 「상품 연결 관리에서 보기」가 뜹니다. 규칙 14로 한 상품·세트상품에 연결은 하나뿐이라 등록할 것이 없기 때문입니다. 위 화면에서 초록 선으로 이어진 짝을 골라 우클릭해 보세요.

1그룹 끝에 붙입니다. 1그룹은 「이 상품의 무엇을 설정하는가」 계열이고 2그룹은 「목록에서의 위치·상태」 계열입니다. 연결은 명백히 1그룹입니다. 2그룹에 넣으면 「사용중지」 바로 위에 놓여 오클릭 위험이 생깁니다.

상품과 세트상품은 이미 정해진 채로 넘어옵니다 — 인터넷상품과 기본WIFI가 모두 선택된 상태에서 기본WIFI 위를 우클릭할 때만 이 항목이 뜹니다. 인터넷상품 위나 한쪽만 고른 상태에서 우클릭하면 항목 자체가 없습니다. WiFi 없이 파는 상품은 기본WIFI 맨 위 「미적용」을 골라 같은 방식으로 등록합니다(AS-IS와 동일).

2등록 모달 — 속성 선택 → 대표 지정
항목내용
읽기 전용업체 · 구분 · 좌측 상품 · 세트상품 — 앞 화면에서 이미 고른 값
셀렉트 3개태그명이 나옵니다(1Gbps(에센스)) · 그 업체가 가진 태그만 · 첫 자리 필수, 나머지는 「없음」 기본 선택(목록 맨 위)
속성 조합고른 태그의 속성으로 표시 — 어느 조합 그룹에 들어가는지
이 조합의 기존 연결같은 조합의 연결 목록 + 현재 대표 배지 — 대표를 켤지 판단하는 근거
대표조합의 첫 연결이면 자동으로 켜지고 끌 수 없음(규칙 5)
저장 불가첫 자리 미선택 · 같은 상품 조합에 이미 연결이 있음(규칙 14)
DESCRIPTION

셀렉트가 태그명인 이유 — 속성만으로는 태그를 특정할 수 없습니다. HCN 100Mbps에 (광랜 1년)~(광랜 4년) 네 태그가 걸려 있습니다. 저장되는 값은 태그 SN 3개이고 속성은 사본으로 따라옵니다(v22 규칙 7).

이미 연결이 있으면 모달이 열리지 않습니다 — 우클릭 항목이 「상품 연결 관리에서 보기」로 바뀝니다. 모달 안 오류 안내는 동시 편집 대비 안전망입니다.

확인 필요 — 자리 태그는 Phase 1에서 수동 선택입니다. Phase 2에서 상품별 태그 등록을 필수화하면 자동 입력으로 바꿉니다.

설명 수정 — 결합할인 분류 우클릭
위 화면에서 상품군 결합할인을 누르고 분류 칸을 우클릭 → 「설명 수정」. KT만 실데이터로 채웠습니다.
3「설명 바꾸기」를 대체하는 새 항목 · 새 모달결합할인 · 분류 칸만
항목내용
진입 변경결합할인 분류 칸 우클릭 메뉴에서 「설명 바꾸기」 자리를 「설명 수정」이 대신함. 항목 칸 · 다른 상품군은 「설명 바꾸기」 그대로
할인명AS-IS 상품명과 같은 값 · 필수. CRM과 신청서가 같이 씀
CRM 설명AS-IS 상품 설명과 같은 값 · 상담사 참고용(할인 조건 등)
신청서에 노출 추가체크박스. 끄면 신청서에 이 할인이 나가지 않음
신청서 설명 추가체크와 무관하게 항상 입력 · 저장, 체크를 켜면 필수. 고객용 짧은 문구 — CRM 설명과 별도 값
하단 설정값 표시AS-IS와 같이 상품 옵션 JSON 읽기 전용 표시 · 개발용이라 추후 제거
목록 표시신청서 노출 중인 분류 칸에 신청서 배지
DESCRIPTION

기존 모달을 고치지 않고 새로 만든 이유 — 「설명 바꾸기」의 버튼명 · 필드 라벨 · JSON 표시가 전 상품 공통 컴포넌트라 바꾸면 모든 카드에 영향이 갑니다(FE 확인). 결합할인 분류에서만 새 모달로 갈아끼웁니다.

이름을 「설명 수정」으로 둔 이유 — 대체하는 「설명 바꾸기」와 이어져 운영자가 바로 알아봄. 「할인」은 위 「상품 할인 설정」과 헷갈려 제외, 「신청서」는 대체 항목이라 제외. 여러 필드를 편집하므로 문구 규칙상 「수정」.

체크를 꺼도 신청서 설명은 지우지 않습니다 — 노출만 멈추고 값은 보관.

결합할인 분류에서 「설명 바꾸기」 숨김 — 개발에서 처리 가능(주인 확인). 방식은 개발 판단.

신청서 설명 입력 제한 없음 — 글자 수 · 줄바꿈 제한 없음. AS-IS 상품 설명과 동일.

인터넷 상품 관리 — 태그 연결 · 상품 연결 등록 · 결합할인 설명 수정 시안 · 카드를 클릭하면 조합이, 우클릭하면 메뉴가 열립니다.
