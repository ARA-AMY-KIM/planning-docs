4기본값 자동 규칙전 구분 동일 · 10/07
시점동작
상품에 첫 초록선이 생김그 짝의 세트상품이 자동으로 기본값. 등록과 무관 — 대표는 속성 조합의 첫 등록, 기본값은 상품의 첫 초록선이 기준
바꾸고 싶을 때두 번째 칸 카드 우클릭 「기본값 지정」 — 모달 없이 즉시 교체. 해제 수단 없음
미사용 세트상품기본값 지정 불가 — 메뉴에 뜨지 않음. 미사용은 상담 상세에 노출되지 않아 기본값이 되면 빈 값이 들어감. 기본값인 세트상품을 사용중지하면 남은 짝으로 승계
기본값 짝의 초록선 삭제남은 초록선 짝 중 하나로 승계(미사용은 건너뜀). 남은 짝이 없으면 기본값도 없음
이관레벨 1순위 세트상품을 초기 기본값으로 (목업은 첫 번째 짝)
DESCRIPTION

상품 조합 등록과 기본값을 묶지 않습니다. 등록은 짝 단위(상품 하나에 여러 개)이고 기본값은 상품 하나에 1개입니다. 묶으면 등록하지 않은 상품은 기본값이 비고, 첫 등록에도 모달이 생깁니다.

「미적용」 특이사항
「미적용」 카드에만 해당하는 규칙 — 한곳에
WIFI 없이 파는 상품의 세트상품 자리입니다. 상품이 아니라서 일반 카드와 다른 점만 모았습니다.
항목규칙일반 기본WIFI와 비교
위치인터넷 기본WIFI 칸 맨 위에 항상—
단독 우클릭「미사용 / 사용」 하나뿐 — 사용 중이면 「미사용」, 미사용이면 「사용」 (AS-IS)다름 — 요금 · 할인 · 이벤트 · 태그 · 플랫폼 메뉴 없음
짝으로 고른 뒤 우클릭기본WIFI 짝과 같은 메뉴. 단 「플랫폼 노출 설정」 없음거의 같음
태그 지정「없음」 태그만 고를 수 있음. 단독 우클릭에는 메뉴가 없어 짝을 고른 뒤 지정다름 — 구성제품 목록 전체가 아님
「태그 없음」 배지「없음」 태그가 아직 없으면 표시 (선택과 무관)같음
플랫폼 노출 설정없음 — 금액 · 설명을 두지 않음다름
기본값될 수 있음 — WIFI 없이 파는 상품의 기본값. 「기본값」 배지도 같은 규칙같음
상품 조합 등록같은 방식으로 등록. 속성 조합의 구성제품 = 「없음」같음
태그가 없을 때속성 조합을 계산할 수 없음 → 등록 모달 [등록] 비활성 · 통신사 변경 매칭에서 빠짐같음
DESCRIPTION

확인 필요 — AS-IS에는 TV · 인터넷전화 · 일반전화의 세트상품 칸에도 「미적용」이 있습니다(AS-IS 연결 데이터 · 디자인 시안). 이 목업은 인터넷만 「미적용」 카드를 그립니다. 같은 규칙을 인터넷 외에도 적용할지 정해야 합니다.
