「없음」 태그 · 연결 2건 — 둘 다 비활성
연결 상품 2건에서 사용 중이라 삭제할 수 없습니다.
일반 태그 · 연결 7건 — [삭제] 비활성
연결 상품 7건에서 사용 중이라 삭제할 수 없습니다.
[삭제] 활성 조건은 「연결 상품 0건」 하나뿐입니다. 「없음」 태그인지 여부와는 무관합니다. [수정] 은 「없음」 태그에서 영구 비활성입니다 — 속성 · 태그명 · 노출 등급이 모두 자동값이라 모달에 바꿀 항목이 없습니다.
실데이터상 「없음」 태그 21건은 모두 연결 1건 이상이라 위 첫 번째 상태가 화면에 바로 보이지는 않지만, 그 자리를 비우는 상품이 전부 단종되면 연결 0건이 되고 그때 삭제가 필요합니다.
HTML title 을 쓰지 않습니다. disabled 버튼은 마우스 이벤트를 받지 못해 브라우저 기본 툴팁이 뜨지 않습니다. 버튼을 래퍼로 감싸고 래퍼에 툴팁을 겁니다. 이때 관리 열 셀의 overflow 를 visible 로 둬야 말풍선이 잘리지 않습니다.
