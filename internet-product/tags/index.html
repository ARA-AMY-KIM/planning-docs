미결 항목

해석 — 기능 정의서 착수 전 확정 필요

이 화면 안에서 결정해야 할 것

  1. 공통 안내 문구 — 전 구분 공통 1종으로 정했으나 문구 미정. 인터넷의 자동 조립 규칙과 인터넷 외의 직접 입력 규칙을 한 문장에 담을지, 규칙 설명을 빼고 순서 변경 안내만 남길지 결정이 필요합니다.
  2. 노출 등급 이관 규칙 — 현재 데이터의 「비인기 상품」(KT 5Gbps·10Gbps 등)을 3종 중 무엇으로 옮길지 미정. 목업에는 3종만 노출했습니다.
  3. ② 상품속성 관리 진입 경로 — 툴바 버튼 삭제 후 GNB 메뉴 직접 진입만 남는지 확인 필요. 태그 등록 시 속성이 없으면 속성부터 만들어야 하는데, 그 동선이 화면에서 끊깁니다.
  4. 사이드패널 [상품 연결 관리에서 보기] 도착지 — ④는 2차에서 조회 전용 VIEW로 축소되고 태그 등록 기능은 ⑤ 조합 표가 흡수합니다. 이 버튼이 ④로 갈지 ⑤로 갈지 결정이 필요합니다.
  5. 결합요금의 관리 단위 — 개발 6.5.4는 태그 단위, 6.6.3 internet_combination.bundle_charge는 조합 단위로 기술되어 있습니다. 조합 단위로 확정되면 이 화면의 결합요금 열·필드가 모두 빠집니다.
  6. 태그 이미지 — AS-IS 태그관리 팝업에 있던 항목이나 TO-BE 설계에 없습니다. 이번 와이어프레임에도 넣지 않았습니다. 폐기인지 누락인지 확인이 필요합니다.

산출물 경계 문제

  1. ①과 ②③의 밀도가 달라집니다. 2차 범위 확정본(2026-09-16)은 ①②③을 1차 산출물 유지로 두었습니다. 이번에 ①을 와이어프레임으로 다시 그리면서 모달 5종(③ 소관)까지 같이 들어왔고, ② 상품속성 관리만 CRM 디자인 재현 목업으로 남습니다. 디자이너가 두 가지 밀도의 문서를 받게 되므로, ②도 같은 밀도로 다시 그릴지 결정이 필요합니다.
