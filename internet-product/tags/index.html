DESCRIPTION

정정 — 앞 버전에서는 테이블 영역 안에만 패널을 그렸는데, 어드민의 실제 사이드패널은 화면 전체 높이입니다. 발송 결과 조회(비즈터널 운영)의 「메시지 상세」 패널을 확인했습니다: position:fixed · right:0 · top:0 · height:100% · width:560px · shadow-xl. GNB까지 덮고 딤(오버레이)은 없습니다. 시안도 그 규격으로 맞췄습니다.

닫기 — ESC · 우상단 ✕ 둘 다. 실제 패널도 ESC로 닫힙니다. 딤이 없어서 바깥 클릭으로는 닫히지 않고, 다른 행의 연결 상품 수를 누르면 패널 내용만 갈아끼웁니다.

패널 구조 — 헤더 「연결 상품」 + ✕. 본문은 태그 정보 카드와 연결 상품 목록 둘로 나뉩니다.

태그 정보는 카드로 묶었습니다. gray-25 배경 + 테두리, 상단에 태그명(17px)과 노출 등급 배지를 한 줄로, 그 아래 구분 · 업체 · 속성 타입 · 속성을 2×2 그리드로 배치합니다. 라벨 위 · 값 아래 세로 스택이라 값이 길어져도 줄이 안 깨집니다. 헤더에 있던 태그명 식별자는 카드와 중복이라 뺐습니다.

연결 상품이 많을 때 — 실측하니 태그 하나에 붙는 연결은 최대 37건이고, 274개 태그 중 238개(87%)가 10건 이하입니다. 20건을 넘는 태그는 5개뿐입니다(전부 「없음」 태그와 KT 스마트셋탑).
이 규모면 더보기나 페이징 없이 목록 영역만 스크롤하는 것으로 충분합니다. 최대 케이스도 스크롤 3화면이면 끝납니다. 대신 태그 정보 카드 · 건수 헤더 · 하단 버튼은 고정하고 목록만 움직이게 해서, 아무리 내려도 지금 무슨 태그를 보고 있는지와 나가는 길이 화면에 남아 있게 합니다.

목록 항목은 두 줄입니다. 1줄 = 상품명 × 세트상품명 — 연결이 「상품 짝」이라는 걸 드러냅니다. 세트상품이 없으면 상품명만 씁니다(「세트상품 없음」이라고 쓰지 않습니다). 2줄 = 속성 타입 조합 3자리이고, 지금 보고 있는 태그는 굵게, 값이 「없음」인 자리는 gray-300으로 흐리게 처리합니다.

이전 시안은 세트상품 없음 · 100Mbps(슬림) · 없음 · 없음처럼 「없음」이 세 번 나왔는데 뜻이 각각 달랐습니다 — 앞의 하나는 세트상품 필드가 비어 있다, 뒤의 둘은 속성 값이 문자 그대로 "없음"인 태그입니다. 지금 포맷은 앞의 것을 없애고 뒤의 둘만 흐리게 남겨 구분합니다.

위 시안은 100Mbps(슬림) 9건으로, 케이스가 골고루 들어 있습니다 — 단품(세트 없음) · 세트 있음 · 3자리 중 「없음」 2개 · 1개 · 0개.

여는 조작은 「행 클릭」입니다. 처음엔 연결 상품 수만 클릭하게 했는데, 패널이 우측 560px를 덮으면 연결 상품 컬럼 자체가 가려져서 패널이 열린 상태로 다른 태그를 눌러볼 수가 없었습니다. 기존 「메시지 상세」 패널은 트리거가 맨 왼쪽 컬럼(메시지 ID)이라 이 문제가 없습니다.
행 아무 데나 누르면 열리고, 수정 버튼과 드래그 핸들만 제외합니다. 연결 상품 수는 링크 스타일을 유지해 클릭 가능하다는 신호로 남깁니다. 연결 0건인 행은 열리지 않습니다.

선택한 행은 blue-50으로 표시합니다. 읽기 전용이며 여기서 연결을 바꾸지 않습니다. 하단 [상품 연결 관리에서 보기]는 그 태그로 필터가 걸린 상태로 이동합니다. 연결 0건이면 목록 자리에 "연결된 상품이 없습니다"를 두고, 리스트의 숫자도 회색으로 클릭을 막습니다.

AS-IS의 「전체 / 신청서 미표기 / 플랫폼 표기」는 폐기합니다. 세 값의 기준점이 각각 전체 · 신청서 · 플랫폼으로 달라 운영자가 매번 기준을 바꿔 읽어야 했습니다. 이관 규칙 — 각 값이 신청서 · 플랫폼 체크 조합 중 무엇에 대응하는지 개발 확인 필요. internet_tag 태그상태 값 분포를 뽑으면 죽은 값이 있는지도 함께 확인됩니다.
