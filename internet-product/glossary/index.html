01

상담상세 노출 규칙

상담상세의 두 드롭다운에 무엇이 나오는지를 구분별로 정리했습니다. 명세

인터넷인터넷 외 (TV · 전화)
태그 보기 상품 조합이 등록된 것만 두 드롭다운에 나옵니다 상품 보기와 같은 규칙
상품 보기 초록선이 있으면 나옵니다. 상품 조합 등록과는 무관합니다 초록선이 있으면 나옵니다. 상품에 태그가 지정돼 있으면 상품명(태그명)으로 붙습니다
두 번째 드롭다운 기본값 — 기본값으로 지정된 세트상품. 세트상품이 있는 상품은 반드시 1개가 기본값입니다
여러 후보 중 고르는 기준 대표 — 업체 + 속성 조합마다 1개. 통신사를 A에서 B로 바꿨을 때 B에 같은 속성의 상품이 여러 개면, 태그 보기에서 상품 보기로 넘어갈 때 대표를 보여줍니다 기본값 — 상품 1개마다 세트상품 1개. 새로 지정하면 기존 값이 교체됩니다
미사용 상품 상담상세 · 플랫폼 모두 노출되지 않습니다. 태그가 붙어 있어도 겉으로 나가는 곳이 없습니다 개정
AS-IS에서 바뀌는 점 — 인터넷 외의 두 번째 드롭다운 기본값은 지금까지 인터넷 상품 관리에서 정할 수 없어 「태그 연결」(왼쪽 상품마다 1건)로 관리했습니다. V2는 이 역할을 기본값으로 옮기고, 상품 조합 등록은 인터넷 전용으로 남깁니다.

동작 용어

운영자가 인터넷 상품 관리에서 하는 일. 우클릭 버튼명은 이 용어를 그대로 씁니다. 명세

용어뜻대상우클릭 버튼명 · 결과
태그 지정 상품 카드 하나에 태그를 붙이는 일 전 구분 태그 지정 → 모달. 인터넷상품은 속도(필수) + 추가구성옵션(선택) 2칸, 기본WIFI · 인터넷 외는 1칸
상품 조합 등록 개정 인터넷 상품 조합을 속성 조합에 올려 태그 보기에 나오게 만드는 일. 태그는 두 카드에 지정된 값을 그대로 씁니다 인터넷 상품 조합 등록 → 첫 조합이면 모달 없이 즉시, 기존 조합이 있으면 모달. 이미 등록돼 있으면 상품 조합 관리에서 보기
대표 같은 업체 · 같은 속성 조합에 등록된 상품 조합 중 기준이 되는 1건 인터넷 등록 모달의 「이 상품 조합을 대표로」로 지정. 변경은 상품 조합 관리에서만. 속성 조합의 첫 조합은 자동으로 대표 개정
기본값 개정 상품을 고르면 상담상세 두 번째 드롭다운에 미리 들어갈 세트상품 인터넷 외 기본값 지정 → 모달 없이 즉시 · 토스트. 해제 수단은 없습니다 — 반드시 1개가 기본값이어야 합니다
플랫폼 노출 관리 개정 상품 하나가 플랫폼 · 신청서에 어떻게 나갈지 정하는 일 전 구분 플랫폼 노출 관리 → 모달. 추가 노출(신청서 · 플랫폼) 체크 + 월요금 · 플랫폼 노출용 설명(인터넷은 결합요금 추가)
「기본값」은 9/30판의 결정을 뒤집은 것입니다 — 당시엔 카드 이름 뒤에 붙는 우선순위명 「(기본)」과 글자가 겹친다는 이유로 「자동 선택」을 택했습니다. 그런데 「자동 선택」이 시스템이 알아서 골랐다는 뜻으로 읽혀서, 운영자가 직접 정하는 값이라는 사실이 가려졌습니다. 겹치는 글자보다 틀린 어감이 더 큰 문제라고 보고 바꿨습니다. 「기본값」은 해제 수단이 없는 규칙과도 결이 맞습니다 — 기본값 없는 셀렉트박스는 성립하지 않으니까요. 해석

함께 정해진 규칙

  • 초록선이 없는 상품 조합에서는 등록도 기본값 지정도 할 수 없습니다. 초록선은 판매 가능한 조합이라는 뜻입니다. 메뉴 항목 자체가 뜨지 않습니다.
  • 상품 조합 등록 · 기본값 지정 메뉴는 조합을 고른 뒤 세트상품 위에서 우클릭할 때만 뜹니다.
  • 세트상품에 붙는 태그는 1개가 원칙입니다. 2개면 운영 데이터 오류입니다.
  • 인터넷상품의 속도 태그가 없으면 상품 조합을 등록할 수 없습니다.
  • 이미 기본값인 세트상품에는 메뉴 항목이 뜨지 않습니다. 카드의 「기본값」 배지가 이미 그 사실을 보여주고, 해제 수단도 없기 때문입니다. 개정
  • 대표 변경과 상품 조합 삭제는 인터넷 상품 관리에서 할 수 없습니다. 상품 조합 관리로 넘어가야 합니다. 05 참고 개정

한 줄로는 — 인터넷 상품 관리는 만들고, 상품 조합 관리는 고치고 지웁니다.

왜 나눴나 — 한 모달에 등록 · 대표 변경 · 삭제를 모두 넣으니 주 버튼이 여러 개가 되고, 그걸 감당하려고 삭제 확인 · 되돌리기 · 임시 저장 같은 장치가 계속 붙었습니다. 장치가 늘어나는 것은 설계가 정교해지는 신호가 아니라 모달이 자기 일이 아닌 걸 하고 있다는 신호로 보고 역할을 잘랐습니다. 자른 뒤 그 장치는 전부 사라졌고, 등록 모달의 버튼은 [취소] [등록] 둘만 남았습니다. 해석

대표를 바꾸려면 반드시 상품 조합 관리로 넘어가야 합니다. 의도한 제약이며, 인터넷 상품 관리에서 이미 등록된 조합을 우클릭하면 상품 조합 관리에서 보기가 떠서 그 속성 조합으로 필터가 걸린 채 열립니다.
