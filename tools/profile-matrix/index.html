발신프로필 매트릭스 정리

bizId별 응답을 붙여넣으면 중복 제거 후 O/X 매트릭스를 자동으로 만듭니다.

1 bizId 응답 추가

같은 이름으로 다시 추가하면 최신 응답으로 덮어씁니다. senderKey가 중복된 항목은 자동으로 1건으로 합칩니다.

2 추가된 bizId

아직 추가된 응답이 없습니다.

3 발신프로필 매트릭스

O = 해당 bizId에 등록됨 · X(노란칸) = 미등록 · 회색 행 = 휴면 프로필. 맨 아래 합계 행은 각 bizId의 등록 수(휴면 포함)입니다. 발송 가능 수만 보려면 휴면 행을 빼고 세면 됩니다.
