개요

전체 업체의 등록·수정 모달을 풀페이지로 전환한다. 입력 항목과 필수 여부는 기존 모달과 같고, 항목을 그룹으로 묶어 배치한다. 업체 용도(PNB-1954)는 별도 그룹으로 포함한다.

화면 이동 규칙

등록·수정은 현재 창에서 페이지 이동한다. 목록 상태(검색어·필터·페이지)는 기본으로 유지한다.

목록 → 수정현재 창에서 수정 페이지. 수정 버튼은 링크로 구현해 우클릭 새 탭·새 창 열기, Ctrl/⌘+클릭, 휠 클릭 허용진입 전 상태 기억
등록 저장 성공목록 + 토스트초기화, 1페이지
수정 저장 성공 / 삭제 성공목록 + 토스트진입 전 상태 복원
