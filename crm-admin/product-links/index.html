이미 연결이 있으면 메뉴 항목이 바뀝니다 — 「상품 연결 등록」 대신 「상품 연결 관리에서 보기」가 뜹니다. 규칙 14로 한 상품·세트상품에 연결은 하나뿐이라 등록할 것이 없기 때문입니다. 위 시안에서 선택을 바꿔가며 눌러보세요 — 위쪽 목록 화면이 실제로 그 상태로 바뀝니다.

1그룹 끝에 붙입니다. 1그룹은 「이 상품의 무엇을 설정하는가」 계열이고 2그룹은 「목록에서의 위치·상태」 계열입니다. 연결은 명백히 1그룹입니다. 2그룹에 넣으면 「사용중지」 바로 위에 놓여 오클릭 위험이 생깁니다.

상품과 세트상품은 이미 정해진 채로 넘어옵니다 — 좌측(상품)과 우측(세트상품)이 모두 선택된 상태에서 우클릭하기 때문입니다. 우측을 안 고르면 세트상품은 미적용으로 넘어갑니다.

DESCRIPTION

셀렉트가 태그명인 이유 — 속성만으로는 태그를 특정할 수 없습니다. HCN 100Mbps에 (광랜 1년)~(광랜 4년) 네 태그가 걸려 있습니다. 저장되는 값은 태그 SN 3개이고 속성은 사본으로 따라옵니다(v22 규칙 7).

이미 연결이 있으면 모달이 열리지 않습니다 — 우클릭 항목이 「상품 연결 관리에서 보기」로 바뀝니다. 모달 안 오류 안내는 동시 편집 대비 안전망입니다.

확인 필요 — 자리 태그는 Phase 1에서 수동 선택입니다. Phase 2에서 상품별 태그 등록을 필수화하면 자동 입력으로 바꿉니다.
