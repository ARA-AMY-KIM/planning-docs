확인 시나리오

위 화면은 클릭해서 확인할 수 있다. 데이터는 설명용 예시이며 새로고침하면 초기화된다. 각 케이스는 아래 업체로 확인한다. 항목 정의는 [화면기획서] 탭 참고.

  1. [상부점 지정] → 업체 검색(라이언렌탈, 콘통신) → 접수 상품군 선택 → 저장 → 목록에 '거래 중'으로 추가
  2. 라이언렌탈·콘통신을 모두 지정한 뒤 [상부점 지정] → '지정할 수 있는 업체가 없습니다' 안내 확인
  3. 현대렌탈케어 수정 → 렌탈 칩이 잠겨 있고 정책 안내 문구 확인 (렌탈 정책 등록됨 가정)
  4. 죠르디통신 수정 → 거래 중지 선택 → 안내 문구 확인 → 저장 → 확인 팝업 → 거래 중지 반영
  5. 예스렌탈(거래 중지) 수정 → 거래 중으로 변경 → 확인 팝업 없이 저장
  6. 접수 상품군 필터 '인터넷', 상부점 상태 필터 '거래 중지'로 조회
  7. 저장 후 [변경 내역]에서 접수 상품군·상부점 상태·비고 변경 기록 확인

개요

CRM Admin > 업체 관리 > 상부점 관리(신규). 전체 업체에서 업체 용도가 '상부점'인 업체를 Admin 상부점으로 지정하고, 접수 상품군과 상부점 상태를 관리한다. 이 탭은 Figma 작업용 화면기획서이며, 실제 동작은 [목업] 탭에서 확인한다.

화면구성
목록필터(검색 기준·검색어 / 접수 상품군 / 상부점 상태 / 줄 수), [변경 내역] [상부점 지정], 목록 테이블
상부점 지정 모달업체 선택, 접수 상품군, 비고. 상태 '거래 중', 거래 시작일은 지정일로 자동
상부점 수정 모달업체(읽기 전용), 상부점 상태, 접수 상품군, 비고, 거래 시작일·최종 수정일시(읽기 전용)
거래 중지 확인 팝업거래 중 → 거래 중지로 저장할 때
변경 내역 모달전체 업체와 같은 형식
확장 자리 — CRM BE 미팅에서 하부점 관리가 필요하다고 정해지면 메뉴명이 '상/하부점 관리'로 바뀌고 '구분(상부점/하부점)'이 추가된다. 추가 위치는 목록 첫 컬럼, 필터 첫 자리(검색 다음), 지정 모달 첫 필드로 비워둔다.
